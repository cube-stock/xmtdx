# 0.3.1 变更说明

公共查询方法与结果类型不变。本次修复错误返回与连接生命周期，保留 Python ≥3.10 和核心零依赖。

## 连接

- 显式连接、上下文进入与查询使用同一重试配置；响应解析及 K 线等语义校验失败可切换候选主机。
- 异步握手/请求取消会关闭受影响连接并传播 `CancelledError`，下次请求重新连接。
- 关闭会立即解除流引用，并限时等待；心跳异常也不会阻止底层连接释放。重复连接不会替换正在运行的心跳。
- 无效端口、非有限或非正超时、非整数重试次数抛出 `ValueError`；心跳间隔须有限，非正值仍表示禁用。

## 更严格的数据行为

- 沪深证券全集按实际页长推进，过滤前核对数量、市场和重复代码，提前空页不再作为完整列表返回。
- 历史资金流回退要求逐笔成交量覆盖对应日线，允许一手舍入误差；不足时抛出 `TdxResponseError`。
- 今日分时在周末和开盘前直接返回空，其余时间必须经过同日日线与参考行情校验；缺少校验数据会报错。
- `get_price_limits()` 在日线失败或为空、无法确认上市天数时返回 `(None, None)`。
- 纯规则 `compute_price_limits()` 未提供 `listed_days` 时仅计算常规板块规则；非有限昨收或非正整数上市天数抛出 `ValueError`。
- 非空截断响应与不存在的日期不再作为有效数据接受；市场统计不再用截断残差掩盖计数不守恒。

## 在线诊断

`python scripts/validate_live.py --json` 移除本进程的代理环境变量、记录路由及初始连接对端，
不修改系统网络设置。检测到 VPN/TUN 路由时停止直连验证，未知路由明确标记尚未验证直连。

每项检查增加 `status`（`pass/fail/warn/skipped`），保留 `ok`，仅通过时为真；
金额覆盖率只作警告。市场、周期独立报告，缺少前置数据时记录跳过原因。
握手探测或必需查询失败使进程返回非零退出码。近期公网失败见 [验证矩阵](protocol-coverage.md#本次在线验证2026-10-27)。
